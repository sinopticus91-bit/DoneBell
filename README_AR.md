يخبرك DoneBell عند انتهاء مهمة طويلة في علامة تبويب المتصفح حتى لا تضطر إلى الرجوع إليها باستمرار.

## الميزات الرئيسية

اكتشاف انتهاء ردود الذكاء الاصطناعي، ومراقبة أي عنصر في الصفحة، وتشغيل صوت مخصص أو الجرس المدمج، وملفات تنبيه عامة وإعدادات خاصة بكل موقع، وAuto-Watch اختياري لكل موقع.

**AI:** ChatGPT · Claude · Gemini · DeepSeek · Grok · Perplexity · Microsoft Copilot · Poe · Le Chat · You.com

## سلوك علامات التبويب

يمكن ضبط ثلاث خيارات بشكل مستقل: الانتقال تلقائيًا إلى علامة التبويب المكتملة، إيقاف التنبيه عندما تفتحها بنفسك، وخيار فرعي لإيقافه أيضًا إذا انتقل DoneBell إليها تلقائيًا.

## التثبيت اليدوي

افتح `edge://extensions/` أو `chrome://extensions/`، فعّل وضع المطور، اختر **Load unpacked** ثم مجلد `extension/`.

## الخصوصية

لا يستخدم `<all_urls>`. يطلب Auto-Watch إذن الموقع الذي تفعّله فقط. يتم إعداد التشخيص محليًا ولا يتضمن مطالبات الذكاء الاصطناعي أو إجاباته.

## الملاحظات

استخدم **Report a problem** لإرسال تشخيص تقني أو **Suggest an idea** لاقتراح ميزة.
