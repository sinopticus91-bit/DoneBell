DoneBell은 브라우저 탭의 오래 걸리는 작업이 끝났을 때 알려 주므로 계속 탭을 확인할 필요가 없습니다.

## 주요 기능

AI 응답 완료 감지, 임의의 페이지 요소 감시, 사용자 지정 오디오 또는 내장 벨, 전역 프로필과 사이트별 설정, 사이트별 선택형 Auto-Watch를 지원합니다.

**AI:** ChatGPT · Claude · Gemini · DeepSeek · Grok · Perplexity · Microsoft Copilot · Poe · Le Chat · You.com

## 탭 동작

완료된 탭으로 자동 전환, 사용자가 직접 완료된 탭을 열 때 알림 중지, DoneBell이 자동으로 전환했을 때도 중지하는 하위 옵션을 각각 설정할 수 있습니다.

## 수동 설치

`edge://extensions/` 또는 `chrome://extensions/`를 열고 개발자 모드를 켠 다음 **Load unpacked**에서 `extension/` 폴더를 선택하세요.

## 개인정보

`<all_urls>` 권한을 사용하지 않습니다. Auto-Watch는 사용자가 활성화한 사이트에 대해서만 권한을 요청합니다. 진단 정보는 로컬에서 준비되며 AI 프롬프트나 답변을 포함하지 않습니다.
