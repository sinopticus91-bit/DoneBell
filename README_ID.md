DoneBell memberi tahu saat tugas lama di tab browser selesai, jadi Anda tidak perlu terus mengeceknya.

## Fitur utama

Mendeteksi selesainya respons AI, memantau elemen halaman apa pun, memutar audio sendiri atau bel bawaan, profil global dan pengaturan per situs, serta Auto-Watch opsional per situs.

**AI:** ChatGPT · Claude · Gemini · DeepSeek · Grok · Perplexity · Microsoft Copilot · Poe · Le Chat · You.com

## Perilaku tab

Tiga opsi dapat diatur terpisah: otomatis pindah ke tab selesai, hentikan peringatan saat Anda sendiri membuka tab itu, dan subopsi untuk menghentikannya juga bila DoneBell yang berpindah otomatis.

## Instalasi manual

Buka `edge://extensions/` atau `chrome://extensions/`, aktifkan Developer mode, pilih **Load unpacked**, lalu pilih folder `extension/`.

## Privasi

Tidak memakai `<all_urls>`. Auto-Watch hanya meminta izin untuk situs yang Anda aktifkan. Diagnostik dibuat lokal dan tidak memuat prompt atau jawaban AI.

## Umpan balik

Gunakan **Report a problem** untuk diagnostik teknis atau **Suggest an idea** untuk usulan fitur.
