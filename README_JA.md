DoneBell はブラウザータブの長時間タスクが完了したときに通知し、何度も確認する手間を減らします。

## 主な機能

AI 応答の完了検出、任意のページ要素の監視、カスタム音声または内蔵ベル、全体プロファイルとサイト別設定、サイト単位の Auto-Watch。

**AI:** ChatGPT · Claude · Gemini · DeepSeek · Grok · Perplexity · Microsoft Copilot · Poe · Le Chat · You.com

## タブの動作

「完了タブへ自動切替」「自分で完了タブを開いたら通知を停止」「DoneBell が自動切替した場合も停止」を別々に設定できます。

## 手動インストール

`edge://extensions/` または `chrome://extensions/` を開き、デベロッパーモードを有効にして **Load unpacked** から `extension/` フォルダーを選択します。

## プライバシー

`<all_urls>` は使用しません。Auto-Watch は有効化したサイトだけに権限を要求します。診断はローカルで生成され、AI のプロンプトや回答は含みません。
