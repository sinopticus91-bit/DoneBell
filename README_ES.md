DoneBell te avisa cuando termina una tarea larga en una pestaña del navegador para que no tengas que volver a comprobarla constantemente.

## Funciones principales

Detecta el final de respuestas de IA; vigila cualquier elemento de una página; reproduce un sonido propio o el timbre integrado; permite perfiles globales y ajustes por sitio; Auto-Watch es opcional por sitio.

**AI:** ChatGPT · Claude · Gemini · DeepSeek · Grok · Perplexity · Microsoft Copilot · Poe · Le Chat · You.com

## Comportamiento al abrir pestañas

Puedes activar por separado «cambiar automáticamente a la pestaña terminada», «detener la alerta cuando yo abra la pestaña» y el subajuste «detenerla también si DoneBell cambia automáticamente».

## Instalación manual

Abre `edge://extensions/` o `chrome://extensions/`, activa el modo desarrollador, pulsa **Load unpacked** y selecciona la carpeta `extension/`.

## Privacidad

No usa `<all_urls>`. Auto-Watch solicita permiso únicamente para el sitio que activas. Los diagnósticos se preparan localmente y no incluyen tus prompts ni respuestas de IA.

## Comentarios

Usa **Report a problem** para adjuntar diagnóstico técnico o **Suggest an idea** para proponer funciones.
