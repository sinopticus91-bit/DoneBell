DoneBell informuje, gdy długie zadanie w karcie przeglądarki się zakończy, więc nie trzeba jej ciągle sprawdzać.

## Najważniejsze funkcje

Wykrywanie końca odpowiedzi AI, obserwacja dowolnego elementu strony, własny dźwięk lub wbudowany dzwonek, profile globalne i ustawienia per witryna oraz opcjonalny Auto-Watch dla każdej witryny.

**AI:** ChatGPT · Claude · Gemini · DeepSeek · Grok · Perplexity · Microsoft Copilot · Poe · Le Chat · You.com

## Zachowanie kart

Trzy niezależne opcje: automatycznie przełącz na ukończoną kartę, zatrzymaj alert gdy sam ją otworzę oraz podopcja zatrzymania również wtedy, gdy DoneBell przełączy się automatycznie.

## Instalacja ręczna

Otwórz `edge://extensions/` lub `chrome://extensions/`, włącz tryb dewelopera, wybierz **Load unpacked** i wskaż folder `extension/`.

## Prywatność

Bez `<all_urls>`. Auto-Watch prosi o dostęp wyłącznie do witryny, którą włączysz. Diagnostyka powstaje lokalnie i nie zawiera promptów ani odpowiedzi AI.
