DoneBell сообщает, когда долгая задача во вкладке браузера закончилась, чтобы не приходилось постоянно возвращаться и проверять её вручную.

Есть отдельный AI-режим для популярных чат-интерфейсов и универсальное наблюдение за элементами страницы для остальных веб-инструментов.

## Главное

- Отслеживание завершения AI в ChatGPT, Claude, Gemini и DeepSeek, плюс общий детектор для дополнительных AI-сайтов.
- Универсальный watcher: дождаться исчезновения/скрытия элемента, изменения текста, включения или отключения кнопки.
- Встроенный звонок или свой локальный аудиофайл, живая громкость и повтор до подтверждения.
- Системное уведомление, мигающий `ГОТОВО` в заголовке и крупная кнопка подтверждения прямо на странице.
- Общие профили оповещений и отдельные overrides для сайтов.
- Auto-Watch с разрешением отдельно на каждый сайт и без `<all_urls>`.
- 18 языков интерфейса и настройка внешнего вида.
- Локальная диагностика, GitHub-багрепорты и предложения функций.
- Ненавязчивая ссылка поддержки через Boosty; DoneBell не обрабатывает платежи сам.

## Поведение вкладок в v0.5.6

Три действия теперь независимы:

1. **Автоматически переключаться на завершённую вкладку.**
2. **Останавливать сигнал, когда я сам открываю завершённую вкладку.**
3. **Также останавливать, если DoneBell сам переключил меня на неё** — отдельный подпункт, по умолчанию выключен.

Поэтому DoneBell может сам показать готовый результат, но продолжать сигнал до явного нажатия `✓ Закрыть`; либо, если включить подпункт, считать автоматический переход подтверждением.

Эти же настройки доступны отдельно для поддерживаемых сайтов.

## Приватность

- Нет `<all_urls>`.
- Ручное наблюдение использует временное `activeTab` после явного клика пользователя.
- Auto-Watch запрашивает постоянное разрешение только для сайта, который пользователь включил.
- При выключении Auto-Watch разрешение сайта удаляется.
- Настройки, диагностика и пользовательский звук хранятся локально в storage расширения.
- Аккаунт DoneBell и backend для работы не нужны.
- Баг-репорт формируется локально и передаётся только после явного действия.
- Диагностика не предназначена для сбора текста AI-промптов и ответов.

## Ручная установка

1. Скачайте или клонируйте репозиторий.
2. Откройте `edge://extensions/` или `chrome://extensions/`.
3. Включите **Режим разработчика / Developer mode**.
4. Нажмите **Загрузить распакованное / Load unpacked**.
5. Выберите папку `extension/`.
