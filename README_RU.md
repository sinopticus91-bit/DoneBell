# 🔔 DoneBell

**Public Beta · v0.5.0 · Chrome / Edge**

DoneBell сообщает, когда долгая задача во вкладке браузера закончилась, чтобы не приходилось постоянно возвращаться и проверять её вручную.

Есть отдельный AI-режим для популярных чат-интерфейсов и универсальный watcher элементов для остальных веб-инструментов.

[English README](README.md)

## Что умеет DoneBell

- Следить за генерацией AI и сообщать о завершении.
- Следить за выбранным элементом страницы до его исчезновения, скрытия, изменения текста, включения или отключения.
- Проигрывать встроенный звонок или выбранный пользователем локальный аудиофайл.
- Менять громкость прямо во время воспроизведения.
- Повторять сигнал до явного подтверждения.
- Показывать системное уведомление.
- Мигать `ГОТОВО` в заголовке вкладки.
- При желании переключаться на завершённую вкладку.
- При желании останавливать звук, когда завершённая вкладка становится активной.
- Показывать поверх страницы крупную кнопку **Остановить звук**.
- Использовать общие профили оповещений и отдельные настройки для каждого сайта.
- Автоматически включать наблюдение на выбранных сайтах после отдельного разрешения пользователя.
- Настраивать шрифт, цвета, бейджи детекторов и язык интерфейса.
- Локально подготавливать технический отчёт для баг-репорта.

## Приватность

DoneBell старается запрашивать минимально необходимый доступ.

- Нет разрешения `<all_urls>`.
- Ручное наблюдение использует временное `activeTab` после нажатия пользователем на расширение.
- Auto-Watch включается отдельно для каждого сайта и запрашивает постоянный доступ только к его origin.
- При выключении Auto-Watch разрешение сайта удаляется.
- Настройки, диагностика и пользовательский аудиофайл хранятся локально в storage расширения.
- Аккаунт DoneBell и backend для работы не нужны.
- Баг-репорт формируется локально и передаётся только после явного действия пользователя.
- Диагностика спроектирована так, чтобы не включать тексты AI-промптов и ответов.

## Ручная установка Public Beta

Пока версии в магазинах ещё готовятся:

1. Скачайте или клонируйте репозиторий.
2. Откройте `edge://extensions/` или `chrome://extensions/`.
3. Включите **Режим разработчика / Developer mode**.
4. Нажмите **Загрузить распакованное / Load unpacked**.
5. Выберите папку `extension/` из этого репозитория.
6. При желании закрепите DoneBell на панели браузера.

Для ручного обновления замените локальные файлы новой версией и нажмите **Перезагрузить / Reload** на странице расширений.

## Обратная связь

DoneBell находится в Public Beta. Изменения интерфейсов AI-сайтов иногда могут ломать детекторы, поэтому реальные баг-репорты особенно полезны.

- **🐞 Сообщить о проблеме** в DoneBell подготавливает диагностику и открывает GitHub Issue.
- **💡 Предложить идею** открывает feature request.
- Можно открыть Issue вручную прямо в этом репозитории.

Не публикуйте в Issue приватный текст ваших разговоров с AI.
